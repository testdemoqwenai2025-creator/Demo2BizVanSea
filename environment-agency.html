Real-Time Air Quality Index
AQI by city across Cascadia. Data from Open-Meteo Air Quality API (uses CAMS European model + NOAA data, free, no API key). PUBLIC
AQI Scale: 0-50 Good 51-100 Moderate 101-150 Sensitive Groups 151-200 Unhealthy 201-300 Very Unhealthy 301+ Hazardous
River & Stream Conditions
Real-time streamflow data from USGS WaterWatch. Shows discharge (cfs) and gauge height for key Cascadia rivers. USGS
Active Weather Alerts
Live alerts from NOAA National Weather Service for WA, OR, and national. Updated every 5 minutes. NOAA NWS
Toxic Release Inventory (TRI) Facilities
EPA Toxics Release Inventory — facilities in Washington state that report chemical releases. Data from EPA Envirofacts REST API. EPA
Note: TRI data covers facilities that manufacture, process, or otherwise use >25,000 lbs of toxic chemicals annually. WA has ~1,010 reporting facilities. Most recent reporting year is the most recent EPA TRI National Analysis.
Regional Energy Mix
Electricity generation by source for WA, OR, and BC. Data from EIA (US) and BC Energy Council (Canada). EIA BC Hydro
Public Data Sources — All Taxpayer-Funded, Freely Accessible
NOAA NWS API
api.weather.gov — Weather alerts, forecasts, observations. Public domain.
USGS Water Services
waterservices.usgs.gov — Real-time streamflow, groundwater, water quality. Public domain.
EPA Envirofacts
data.epa.gov/efservice — Facility emissions, TRI, Superfund, air emissions. Public domain.
EIA API
api.eia.gov — Electricity generation, fuel sources, transmission. Free with API key.
Open-Meteo Air Quality
api.open-meteo.com — AQI forecasts from CAMS + NOAA. Free, no key.
Environment Canada
weather.gc.ca — Canadian weather, air quality, climate. Open data license.
Philosophy: All environmental data is collected by taxpayer-funded agencies and should be freely accessible to the public. No government should restrict access to environmental data, and no private platform should gate it behind subscriptions. This page is built entirely from public sources to demonstrate that — defensibility comes from integration and interpretation, not data hoarding.
