## Platform Features

Every page includes the following persistent controls:

| Control | Description |
|---------|-------------|
| **Home** | Return to the Overview landing page |
| **AI Search** | Slide-out AI chat panel for querying corridor intelligence |
| **Login** | Client authentication (connects to the full platform) |
| **Get Started** | Onboarding flow for new clients |
| **Dark / Light** | Theme toggle (persists across sessions) |
| **Mobile Menu** | Hamburger navigation on screens under 900px |

## About AIBizVan360

AIBizVan360 is an **AI-powered** regional intelligence platform for the **Vancouver-Seattle (Cascadia) economic corridor**. It parses and delivers only the most relevant, client-specific intelligence across government, economics, demographics, transportation, resources, and real-time business news from 5+ regional publications.

Logged-in clients receive curated, AI-filtered insights tailored to their industry and interests — eliminating noise and surfacing what matters.

This demo is auto-synced from the private `BizVanSea` repository via GitHub Actions.
